# Financial Data Analysis - PLOTLY

## Overview

This project explores a financial dataset using Python and pandas, with a focus on understanding sales, profit, units sold, discounts, cost of goods sold (COGS), products, countries, segments, and discount bands.

The notebook combines data inspection, cleaning/quality checks, aggregation, and visualization to turn a tabular financial dataset into useful business-oriented observations.

## Project Objectives

* Inspect and understand the financial dataset.

* Check the structure and quality of the data.

* Analyse sales, profit, units sold, discounting, and COGS.

* Compare performance across countries, products, segments, and discount bands.

* Summarize the data with grouped calculations.

* Present findings through interactive Plotly visualizations.

## Dataset

The notebook works with financial records containing fields used for business analysis, including measures such as:

* Sales

* Profit

* Units Sold

* COGS

* Discount

* Discount Band

* Product

* Country

* Segment

## Analysis Workflow

* Data loading and inspection — Load the financial data and examine its structure.

* Data-quality checks — Review columns, data types, missing values, and general data consistency.

* Exploratory analysis — Calculate summaries and compare financial measures.

* Grouped analysis — Aggregate results by dimensions such as country, product, segment, and discount band.

* Visualization — Use Plotly to communicate patterns in the financial data.

* Business interpretation — Use the resulting summaries and charts to identify differences in performance.

## Key Analysis Areas

## Sales and Profit

The project examines sales and profit to understand overall financial performance and how results vary across the dataset.

## Product Performance

Product-level aggregation is used to compare financial outcomes across products.

## Country Performance

Country-level summaries help identify differences in sales and profitability between markets.

## Segment Analysis

## Discount Analysis

Units sold and COGS provide additional context for interpreting revenue and profitability.
