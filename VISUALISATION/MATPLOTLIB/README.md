# Product Sales Analysis & Visualization with Matplotlib

## Overview

This project explores a product-sales dataset using Python, pandas, and Matplotlib. The notebook demonstrates how tabular product data can be transformed into grouped summaries and then communicated through static visualizations.

The analysis focuses on product sales across zones and months, as well as product-level unit prices. It provides a practical example of using pandas for data aggregation and Matplotlib for business-oriented data visualization.

## Project Objectives

Load and inspect the product dataset.

Prepare the data for analysis.

Summarize sales using pandas grouping and aggregation.

Compare sales performance across zones.

Examine sales across months.

Compare unit prices across products.

Create clear visualizations using Matplotlib.

Demonstrate a complete workflow from raw tabular data to visual business summaries.

## Dataset

The notebook works with a product-oriented sales dataset. The analysis uses fields relating to:

* Product

* Zone

* Month

* Sales

* Unit Price

The notebook does not document the original source of the dataset, so no external source or provenance is assumed here.

## Why Matplotlib?

Matplotlib provides direct control over static charts and is one of the core visualization libraries in the Python data-analysis ecosystem.

In this project, it is used to turn grouped pandas results into readable visual comparisons without relying on an interactive dashboard framework.
