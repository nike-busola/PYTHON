# Interactive Product Sales Analysis using Plotly

## Overview

This project combines pandas-based aggregation with interactive Plotly visualizations and demonstrates both Cufflinks-based plotting and Plotly Express.

The notebook focuses on product sales, zones, months, and unit prices, while the updated plotting approach improves chart presentation and labeling.

## Objectives

* Analyse product sales using pandas.

* Summarize sales by zone and month.

* Compare unit prices by product.

* Create interactive visualizations.

* Demonstrate both Cufflinks and Plotly Express approaches.

* Improve chart labels, titles, and layout for clearer communication.

## Dataset

The notebook uses a product-oriented sales dataset with analysis based on fields including:

* Product

* Zone

* Month

* Sales

* Unit Price

## Visualization Methods

## Cufflinks

Cufflinks provides a convenient bridge between pandas and Plotly, allowing DataFrame and Series objects to be plotted interactively.

## Plotly Express

The notebook also demonstrates Plotly Express, which provides a concise interface for building interactive charts.

Using both approaches provides a useful comparison between a pandas-integrated plotting workflow and a more explicit Plotly visualization workflow.
